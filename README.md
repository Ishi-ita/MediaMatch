# 🎬📚 MediaMatch

A modern movie and book recommendation web application built with **React**.

---

## ✨ Features

- 🎬 Discover trending movies
- 📚 Explore popular books
- ❤️ Save favorites
- ⭐ Rate movies and books
- 🔍 Powerful search
- 🤖 Personalized "For You" recommendations
- 👤 User authentication
- 📱 Fully responsive design

---

## 🛠️ Tech Stack

- React.js
- JavaScript (ES6)
- HTML5
- CSS3
- Vite
- React Router
- Axios
- TMDB API *(Coming Soon)*
- Google Books API *(Coming Soon)*

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/Ishi-ita/MediaMatch.git
```

Install dependencies

```bash
npm install
```

Run the project

```bash
npm run dev
```
